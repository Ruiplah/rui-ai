# Rui AI

**让小模型也能干活的本地 AI Agent**

---

## 🎯 项目定位

Rui AI 是一个**本地运行的 AI Agent**——和 Claude Code、OpenClaw 同类。

不是聊天机器人，是能真正执行任务的 Agent：
- 能调用工具（搜索、文件操作、Python 执行等）
- 能多轮推理
- 能控制电脑

**核心差异化：用 9B/12B 本地小模型跑通完整 Agent 工作流。**

---

## 💡 要解决什么问题？

| 对比 | 大模型（GPT-4、Claude） | Rui AI（本地小模型） |
|------|------------------------|---------------------|
| 联网 | 必须联网 | 离线也能用 |
| 费用 | API 调用费（贵） | 只有电费（不到 1 块钱/天） |
| 隐私 | 数据传到云端 | 数据不出本机 |
| 依赖 | 依赖大厂 | 自己掌控 |

**简单说：做一个"免费、隐私、离线"的本地 AI Agent。**

## 🚀 快速开始

### 环境要求：
- Windows 10/11
- AMD 显卡（8GB+ 显存）或 NVIDIA 显卡
- Python 3.10+

### 一键启动：
```bash
# 双击 start_services.bat
```

### 手动启动：
```bash
# 1. 启动 llama-server（推理引擎）
llama-server.exe -m models\Qwen_Qwen3.5-9B-Q4_K_M.gguf -c 32768 --port 8080 --host 0.0.0.0 --path webui -ngl 99 -t 6 -tb 6 -fa on -ub 2048 --no-mmap

# 2. 启动 agent_server（后端）
python agent_server.py
```

### 访问：
- 电脑端：http://127.0.0.1:8080
- 手机端：http://<你的IP>:8080
